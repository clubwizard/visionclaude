Your skills

Short prompt snippets that customize how Claude responds when your message matches one of the trigger keywords. Useful for personal workflows (your cooking style, your dictation conventions, your shorthand). Scoped to your account — other users never see them.
How does this work?
Each skill has a name, a one-line description, optional trigger keywords (comma-separated), and a body. The descriptions are always present in Claude's system prompt so it knows the skill exists. The full body is injected only when your latest message contains a trigger keyword — keeps the prompt small until the skill is actually needed.
  • Name — short identifier (≤64 chars).
  • Description — one line telling Claude what the skill does (≤280 chars).
  • Trigger — comma-separated keywords that activate the full body. Empty = always advertised but never auto-injected.
  • Body — the actual instructions Claude follows when triggered (≤8 KB).

Your MCP connectors

Hook Aside into your own tools (Notion, GitHub, Linear, Sentry, your own services…) by adding remote MCP servers below. Scoped to your account — other users only see the operator's shared tools, never yours.
Quick examples — pick a service to see the URL + how to get a token
Notion — read pages, search, append to databases
URLhttps://mcp.notion.com/sse
AuthBearer secret_…
Get a token: notion.so/profile/integrations → New integration → copy the secret. Share each page you want accessible with the integration.
GitHub — PRs, issues, code search, repo browsing
URLhttps://api.githubcopilot.com/mcp
AuthBearer ghp_…
Get a token: github.com/settings/tokens → Generate (classic) → scopes: repo + read:org.
Linear — issues, projects, comments, status updates
URLhttps://mcp.linear.app/sse
AuthBearer lin_api_…
Get a token: linear.app/settings/api → Create new API key.
Sentry — recent errors, issue triage, release context
URLhttps://mcp.sentry.dev/sse
AuthBearer sntrys_…
Get a token: sentry.io → User Settings → Auth Tokens → Create New Token.
Stripe — customers, charges, subscriptions, refunds
URLhttps://mcp.stripe.com/
AuthBearer rk_… (restricted key) or sk_… (full)
Get a token: dashboard.stripe.com/apikeys. Restricted keys with only the scopes you need are safer.
HubSpot — contacts, deals, companies
URLhttps://app.hubspot.com/mcp/v1/http
AuthBearer pat-…
Get a token: app.hubspot.com → Settings → Integrations → Private Apps → create with the CRM scopes you need.
More services and a full walkthrough on the help page — Supabase, Neon, Vercel, Atlassian, plus self-hosted patterns.
