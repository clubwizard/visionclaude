Getting started

Aside lets you talk to Claude with your voice, optionally with vision from your camera. Everything is per-account: your API keys, conversation history, MCP connectors, and custom skills are all isolated from other users on this server.

The 90-second setup

  1. Go to /account and paste your Anthropic API key. Hit Test to confirm it works. This is the one required key — without it, nothing can talk to Claude.
  2. (Optional) Paste a Deepgram or OpenAI key for high-quality text-to-speech. Without either, the voice client falls back to your browser's built-in TTS (works, but sounds robotic).
  3. Go to /app and tap Talk. Say something.

API keys

All keys are encrypted at rest with the server's master key. The server can only decrypt them at request time, and never sends them back to your browser.

Anthropic (required)

This is what powers Claude itself. You pay Anthropic directly for what you use — Aside just relays.

Where to get one
console.anthropic.com/settings/keys → New API key → copy → paste into the Anthropic field on /account.
What it looks like
sk-ant-api03-AbC...XyZ

Deepgram (optional, recommended)

High-quality, low-latency text-to-speech (the Aura voices) and speech-to-text. The default voice on /app.

Where to get one
console.deepgram.com → sign up → API Keys → create.
What it looks like
a1b2c3d4e5f67890abcdef1234567890

OpenAI (optional)

An alternative set of TTS voices (Alloy, Nova, Echo, …). More expressive than Deepgram, slightly slower. Useful if you want a specific voice character.

Where to get one
platform.openai.com/api-keys → Create new secret key.

Voice client

Open /app on your phone or computer. Grant camera + microphone permission when prompted.

How a turn works

  1. Tap Talk. The mic activates.
  2. Speak normally. When you pause, the recording stops and the transcript is sent to Claude.
  3. If Camera on is checked, the current frame is included as vision context.
  4. Claude responds. The TTS plays automatically through your speakers/headphones.
  5. Tap Talk again for the next turn (the conversation continues until you reload).

Example things to try

  • Point your camera at a label and ask "What does this say?"
  • Show Claude a recipe and ask "Convert this to grams."
  • Show a stack trace on your screen and ask "What's wrong here?"
  • Just chat — vision is optional, you don't need to point the camera at anything.

Choosing a voice

The Voice dropdown lists every voice your configured keys unlock. With only Deepgram set you'll see 10 Aura-2 voices; with OpenAI too, 20. Selection is saved in your browser.

iPhone app

There's no App Store build yet. You have three realistic paths to running Aside on your iPhone, easiest first.

1. Use the web client as a home-screen app (zero install)

This is what most people should start with. It works today, takes 30 seconds, and exercises the same camera + microphone APIs as the native app.

  1. Open https://your-aside-domain/app in Safari on your iPhone.
  2. Tap the Share icon (square with up-arrow) → Add to Home Screen.
  3. Name it (Aside) and tap Add. You now have an icon that opens straight into the voice client.
  4. First time you tap Talk, Safari asks for microphone permission. Grant it. Same for camera.
What works
Voice in, voice out, camera frames sent to Claude, voice selection, vision toggle, conversation history.
What doesn't
Meta Ray-Ban glasses pairing (no Web Bluetooth support in iOS Safari) and reliable background audio. If you don't need those, you may never need the native app.

2. Build & sideload via Xcode (free, requires a Mac)

For native app + Ray-Ban support, with a free Apple ID. The signed build expires every 7 days; plug your phone back in and rebuild to refresh.

  1. On your Mac, clone the Aside repository if you haven't already.
  2. From the repo, regenerate the Xcode project and open it: 
    cd ClaudeVision/ios
xcodegen generate
open ClaudeVision.xcodeproj
  3. Plug your iPhone into your Mac via USB. Unlock the phone and tap Trust This Computer.
  4. In Xcode's toolbar, select your iPhone in the device dropdown.
  5. In Signing & Capabilities, sign in with your Apple ID and pick a unique bundle identifier (e.g. com.yourname.aside).
  6. Hit ⌘R. The app installs and launches.
  7. First launch on the iPhone: Settings → General → VPN & Device Management → Trust your developer certificate.
With a paid Apple Developer account (US$99/year) the sideload signature lasts a year instead of 7 days, and you don't need to keep plugging in.

3. TestFlight (paid, polished, multi-user)

If you have an Apple Developer account, archive the app in Xcode, upload to App Store Connect, invite testers via TestFlight. They install Apple's official TestFlight app and get the build. No expiry. Best for inviting family or coworkers without each plugging into your Mac.

Pointing the app at this server

Once the iOS app is installed, tap the gear icon → Settings:

FieldValue
HostYour Aside domain (no https://, no port). Example: aside.example.com
Port443 if you're behind a reverse proxy that terminates HTTPS (typical), 18790 if you're hitting the container directly
ModeGateway (REST) for this kind of hosted deployment. Channel mode is only for a Mac running Claude Desktop locally.
Gateway API keyOptional but recommended for native use — see below

Authenticating the iPhone (two options)

Option A — session cookie. Open the in-app web view, log in with your email + password just like in a desktop browser. The session cookie persists for 24 hours; you re-log when it expires.

Option B — gateway API key. The operator generates a single shared secret on the server (in the container's .env):

GATEWAY_API_KEY=$(openssl rand -hex 32)

Restart the container, then paste that 64-char hex string into the iOS app's Gateway API key field. The app sends it as X-Gateway-Key on every request — no login required, no cookie expiry. Useful for a phone that's always you.

Same Aside, same account? Either way the iOS app talks to the same Gateway your browser does. Your conversation history, MCP connectors, and skills follow you between devices.

Connecting Meta Ray-Ban glasses

Only available in the native iOS app (Bluetooth APIs aren't web-exposed). In Settings, scroll to Meta Ray-Ban Glasses and tap Register. The app uses the official Meta Wearables toolkit to enumerate paired glasses and stream camera frames. The glasses themselves must already be paired via the Meta View app first — Aside consumes the existing Bluetooth connection.

Skills

Skills are short prompts you install to specialize how Claude responds for you. Think of them as personal preferences Claude follows in specific situations — without you having to repeat yourself every turn.

Each skill has four parts:

FieldWhat it does
NameShort identifier you'll recognize. ≤64 chars.
DescriptionOne line telling Claude what the skill does. ≤280 chars. Always in the system prompt so Claude knows the skill exists.
TriggerComma-separated keywords. When your message contains one, the full body is injected. Empty = advertised but never auto-injected.
BodyThe actual instructions Claude follows when triggered. ≤8 KB.

Example: recipe converter

Name
Recipe converter
Description
Convert cooking volumes to grams using standard density tables.
Trigger
recipe, convert, grams, cups, tbsp, tsp
Body
When the user mentions a cooking quantity in volume
(cups, tbsp, tsp, ml), convert it to grams using standard
density tables. Show the conversion factor briefly.
Example: "2 cups flour ≈ 240g (1 cup ≈ 120g)".

Example: meeting summarizer

Name
Meeting notes
Description
Summarize meeting transcripts into actions, decisions, and open questions.
Trigger
meeting, summarize, action items, recap
Body
When given a meeting transcript or notes, produce three
sections:
- Decisions (what was agreed)
- Actions (who owes what by when)
- Open questions (unresolved items)
Keep each bullet to one line. Use names not pronouns.

Example: shopping mode

Name
Shopping
Description
When shown a product, read price, brand, key specs.
Trigger
(empty — always advertised, body never auto-injected)
Body
When the user points the camera at a product label or
price tag, extract: brand, model/variant, price (with
currency), and any key specs visible. Prefer reading
the actual visible text over inference.

A skill with no trigger is always advertised in Claude's system prompt but the body is never auto-included. Use this when the skill applies broadly and you want Claude to know about it always.

Token cost. Every enabled skill's description sits in your system prompt on every turn. Bodies only ride along when their trigger fires. So 20 skills with 200-char descriptions ≈ 4 KB extra header; a triggered 2 KB body adds another 2 KB just for that turn. Practical limit is around 30 skills before you start feeling it in latency.

MCP connectors

An MCP server is a hosted endpoint that exposes tools (send_message, search_repos, query_database…) over HTTP. When you add one, its tools become available to Claude on your next chat — scoped to your account only.

Two requirements for a connector to work here:

  • The endpoint must use https:// (plain http and private IPs are blocked)
  • It must speak the MCP protocol over HTTP (Streamable HTTP or SSE)
About OAuth. Many hosted MCP services (Notion, GitHub, Linear, Sentry, Atlassian) advertise OAuth as the "official" auth flow. Aside currently sends a static Authorization header — it doesn't drive the OAuth dance for you. All of those services also issue long-lived tokens (integration secrets, personal access tokens, API keys) you can paste here directly. The examples below show the static-token path for each.

Worked example: connect Notion

  1. Visit notion.so/profile/integrations and click New integration. Give it a name (e.g. "Aside"). Submit.
  2. Copy the Internal Integration Secret — it starts with secret_.
  3. Open the Notion pages or databases you want Aside to access, click Share, and add the integration.
  4. On Aside's /account page → Your MCP connectors → + Add a connector, paste:
    Name
    My Notion
    URL
    https://mcp.notion.com/sse
    Auth header
    Bearer secret_ + your integration secret
  5. Hit Save connector, then Test on the new row. You should see "Connected. N tools available."
  6. Go to /app and say something like "Find my notes about the Edinburgh trip in Notion" — Claude can now invoke the Notion tools.

Testing a connector

After saving, hit the Test button on the row. The server opens a probe connection to your URL, lists the tools it advertises, and reports back. You'll see "Connected. N tools available." on success or a clear error if it fails (bad URL, bad auth, server offline, timeout).

What happens during a chat

  1. Your enabled connectors stay disconnected until you actually use them.
  2. On your first /chat after enabling one, Aside opens a connection, lists tools, and merges them into the tool set Claude sees.
  3. Connections are cached per user. If you go idle for 10 minutes, the connection is dropped (auto-reopened on next use).
  4. Each tool call has a 30-second timeout. If your connector hangs, the request fails cleanly instead of blocking the whole chat.
Not seeing your tools in Claude's responses? Claude only invokes tools when it judges them relevant. Mention the tool explicitly ("check my Notion for the meeting note") or hit Test on the connector row first to confirm it's reachable.

Password reset

Two paths:

1. Forgot password link (recommended)

  1. On the login modal, click "Forgot your password?"
  2. Enter your email. A reset link is sent.
  3. Click the link within 1 hour. Set your new password.
  4. Log in with the new password.

A successful reset invalidates your sessions on every other device. If you reset on your phone, your laptop session gets logged out on its next request.

2. Operator override

If email isn't configured on this server, the operator can reset your password via CLI. Ask them.

Troubleshooting

"No Anthropic API key configured"

Go to /account, paste your sk-ant-... key, hit Save. The Anthropic key is the only required one — without it nothing can talk to Claude.

Voice client says "Voice list unavailable" or shows no voices

The voice dropdown is built from your configured TTS keys. Add a Deepgram or OpenAI key on /account. Without either, the browser falls back to its built-in TTS (works, but no provider voices).

MCP connector test fails with "Connection failed"

  • Double-check the URL is reachable from a browser (curl -I https://your-url)
  • Confirm the auth header format the service expects (most want Bearer xxx; some want just xxx)
  • Make sure the server actually speaks MCP at that endpoint — many APIs are HTTP but not MCP

Claude's response is slow

Each tool call costs a round-trip to the MCP server hosting it. If a connector is slow, every chat that uses it inherits that latency. Test your connectors individually to find the slow one and disable or remove it.

I added a skill but Claude doesn't seem to use it

  • Check the skill is enabled (toggle on the row)
  • Make sure your trigger keywords actually appear in your message. Case doesn't matter but exact substring does — "convert" won't match "converted"
  • Try making the description more imperative ("ALWAYS convert..." vs "Sometimes convert...")

Got logged out unexpectedly

If you reset your password on another device, your other sessions are invalidated on their next request. Just log in again — it's by design.

Something else

Ask the operator of this server. The system administrator has access to server logs and can see what failed.
