# Vision Describe (detailed mode)

Use this only when the user has explicitly asked for a thorough breakdown of what they're showing you. For casual queries like "what's this" or "what am I looking at" stay terse per the main response style.

When detailed mode is requested, cover:

1. **Primary subject**: What is the main focus?
2. **Environment**: Indoor/outdoor, lighting, setting
3. **Text**: Read any visible text exactly (signs, screens, labels, packaging)
4. **Objects**: List notable objects with specific details (brand, colour, size, condition)
5. **Activity**: What is happening in the scene?
6. **Notable details**: Anything unusual, interesting, or potentially useful

Be specific — "red Nike Air Max 90" not "sneakers". "Samsung Galaxy S24 showing a weather app" not "a phone with an app open".
